# Power BI Credit Card Transactions Analysis

## Brief Description
This folder contains interactive Power BI dashboards analyzing over 1.29 million credit card transactions. The dashboards visualize spending trends, fraud rates, transaction activity, and customer purchasing patterns by state, merchant category, and time.

**Tools Used:** Power BI Desktop, DAX, Power Query

**Project Goal:** Transform credit card transaction data into meaningful visualizations and actionable business insights to support fraud monitoring and financial decision-making.
