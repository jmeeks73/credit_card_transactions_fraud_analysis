# Python Credit Card Transactions Analysis

## Brief Description
Python scripts and Jupyter notebooks for cleaning, analyzing, and visualizing credit card transactions, spending trends, and fraud patterns.
This folder contains Python scripts and Jupyter notebooks used to clean, transform, and analyze over 1.29 million credit card transactions.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Analysis Performed
- Imported and cleaned credit card transaction data.
- Checked for missing values and duplicate records.
- Analyzed monthly transaction counts and spending trends.
- Calculated total spending and average transaction amounts.
- Examined fraudulent transactions and fraud rates.
- Analyzed spending patterns by category, state, and hour.
- Created charts to visualize transaction activity.

## Project Goal
Use Python to perform data cleaning, exploratory data analysis (EDA), and fraud analysis to identify spending patterns and provide useful business insights.
