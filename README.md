# credit_card_transactions_fraud_analysis

## Project Description
This project analyzes over 1.29 million credit card transactions to identify spending trends, transaction patterns, and potential fraudulent activity.

## Tools Used
- Python (Pandas, NumPy, Matplotlib)
- Microsoft SQL Server
- Power BI
- GitHub

## Project Objectives
- Clean and prepare credit card transaction data using Python.
- Analyze transaction data using SQL queries.
- Identify fraudulent transactions and calculate fraud rates.
- Examine spending patterns by month, state, and category.
- Create interactive Power BI dashboards to visualize results.

## Dataset
- **Total Records:** 1,296,675
- **Total Columns:** 24
- **Key Fields:** Transaction Date, Amount, Merchant, Category, State, and Fraud Flag

## Project Structure
- `data/` – Dataset files
- `notebooks/` – Python analysis
- `sql/` – SQL queries
- `powerbi/` – Power BI dashboards
- `images/` – Dashboard screenshots

## Project Goal
Use data analytics to understand customer spending behavior, identify potential fraud, and provide business insights through Python, SQL, and Power BI.
