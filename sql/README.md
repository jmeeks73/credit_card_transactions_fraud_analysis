# SQL Credit Card Transactions Analysis

## Short Description
Microsoft SQL Server queries used to analyze over 1.29 million credit card transactions, identify fraud patterns, examine customer spending behavior, and generate business insights.

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Analysis Performed
- Imported and explored credit card transaction data.
- Checked for missing values and duplicate transactions.
- Calculated total transactions and total spending.
- Identified fraudulent and legitimate transactions.
- Calculated fraud rates by state and merchant category.
- Analyzed monthly transaction trends.
- Examined average transaction amounts.
- Used SQL queries with GROUP BY, WHERE, ORDER BY, and aggregate functions.
- Analyzed spending patterns by merchant, category, and location.

## Project Goal
Use SQL Server to analyze large transaction datasets, identify potential fraud risks, evaluate spending trends, and provide meaningful business insights for reporting and Power BI dashboards.
